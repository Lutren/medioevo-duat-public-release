What I build

I build MEDIOEVO: local-first tools for AI agents that operate on real systems — code, files, accounts, publishing surfaces and decisions. The core principle is evidence before action.

An AI agent that can use tools needs more than a good answer. It needs evidence before action, explicit uncertainty, a gate before risky work and a handoff so the next session can continue where the previous one stopped.
