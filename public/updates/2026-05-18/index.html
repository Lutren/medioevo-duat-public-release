May 18, 2026 Hub Update

MEDIOEVO Hub now separates public summaries from the local operator system. Public pages are read-only. Local Wabi/Claudio execution remains gated and private.

What changed

  • Public Hub: OSIT, DUAT, Wabi, Agent Hub and roadmap pages added.
  • Local Hub: pending tasks can be prepared as TaskSpecs, reviewed by GhostGate and queued locally.
  • Agent Chat: local-only MSN-style chat endpoint created for agent coordination.
  • Workpack Scheduler: local manual-tick scheduling demonstrated with gates, rollback and dependency checks.
  • Multi-step Workpacks: local multi-step workpacks demonstrated with per-step evidence and rollback.
  • BrowserBridge Selector Pack: dry-run-first browser selection, council ranking and proposal-only conversion documented locally.
  • Source Intake discipline: protected or review material is registered before import, cleanup or publication.
  • Provider status: NVIDIA route remains under review; no retry is allowed in this update.
  • Execution boundary: public pages cannot run Claudio, Wabi or private local tasks.

Follow-up: gated local execution

The internal operator lane now separates TaskSpec, GhostGate, rollback, WitnessLog, scheduler tick and multi-step workpack evidence. This is local-only. The public site does not expose private queues, internal workpack manifests, local endpoints or execution controls.

Follow-up: selector and intake discipline

BrowserBridge selection remains dry-run first and proposal-only by default. External browser send requires explicit gates and public or sanitized payloads. Source Intake remains registration-first: protected material is not imported, copied or published from a raw source.

Evidence boundary

Public summaries include method-level theory, roadmap and QA status. Private workspaces, local paths, protected canon, runtime internals, internal prompt material, datasets, credentials and internal agent messages are excluded.
