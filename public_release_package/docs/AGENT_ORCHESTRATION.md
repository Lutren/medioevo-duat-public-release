# Agent Orchestration

MEDIOEVO treats agent work as gated coordination, not unsupervised publication.

Public concepts:

- Wabi-Sabi: local orchestrator and sensory-cognitive routing layer.
- CEREBRO: canon, memory and structured consultation layer.
- Claudio: local-first operator/runtime.
- MEDIOEVO MessageBus: typed channel system for agent coordination.
- WitnessLog: append-only evidence stream.
- GhostGate / ActionGate: decision gates before risky or external actions.

External actions such as push, deploy, social posting, paid-product edits and model-heavy operations remain gated.
