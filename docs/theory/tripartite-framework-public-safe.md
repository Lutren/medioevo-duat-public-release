# Tripartite Information Framework - Public-Safe Summary

This note summarizes the MEDIOEVO / OSIT information framing for public review.

It is presented as a proposed framework for research, simulation and local-first agent engineering. It is not presented as proof of a universal physical law.

## 1. Physical Information

This layer asks how state, observation and constraints can be modeled in formal systems. Public writing keeps this layer at hypothesis and formal-lab level.

## 2. Information Theory

This layer treats information as something that can be compressed, transformed, distorted or preserved. MEDIOEVO uses this language to reason about residue, uncertainty and update quality.

## 3. Digital Information Systems

This layer is operational. It includes:

- TaskSpec;
- ActionGate;
- GhostGate;
- rollback;
- WitnessLog;
- handoff;
- local evidence;
- public/private boundary checks.

## OSIT as Method

OSIT is used publicly as an operational method:

1. observe current state;
2. classify uncertainty and residue;
3. gate actions;
4. run local verification;
5. leave evidence;
6. hand off state without relying on implicit memory.

## ScienceClaimGate

Strong claims require evidence. Public pages should use language like:

- proposed method;
- synthetic simulation;
- operational evidence;
- public-safe summary;
- falsifier-friendly workflow.

They should not claim prediction certainty, proof-level physics, neutrality guarantees or human-level general autonomy.
