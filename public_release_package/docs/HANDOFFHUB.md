# HandoffHub

HandoffHub is the continuity layer for MEDIOEVO agents.

Instead of a static handoff note, a handoff carries:

- task status;
- owner and destination agent;
- fingerprint;
- evidence references;
- blockers;
- next action;
- epistemic classification: CERTEZA, INFERENCIA, INCOGNITA and BLOQUEO.

The public release shows the concept and UI surface. It does not include private runtime logs or operational source vaults.
