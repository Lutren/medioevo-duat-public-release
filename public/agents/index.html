Agent Hub

The public view describes roles, not live internal messages. Real task queues, ActionGate checks, GhostGate review, rollback and WitnessLog entries remain inside the local operator environment.

Core Orchestrator

Coordinates local work into TaskSpecs, evidence and handoff. Public surface: role only.

Gatekeeper

Classifies actions as approve, review or block before local execution.

Memory Keeper

Maintains briefs, decisions, assumptions, risks and session fingerprints.

Wabi Programmer

Runs fallback-only coding acceptance inside sandboxed local fixtures.

Safe Executor

Keeps apply separate from planning, with rollback before write operations.

Boundary Scanner

Checks public/private boundaries, secrets and blocked claims before release.

Mission Control Reader

Summarizes local operational evidence without executing or mutating.

Wabi MCP Bridge Planner

Designs safe read-only and draft-only tool access before any gated write path.

DUAT Display Agent

Summarizes synthetic simulation and evidence surfaces without prediction claims.

GEODIA Simulation Agent

Tracks local simulation status, test evidence and replay-friendly outputs.

What is not public

Internal chat logs, private queues, protected source material, local paths, runtime code and credentials are not bridged to this site.
