# MEDIOEVO Overview

MEDIOEVO is a cognitive engineering and agent orchestration framework focused on reducing informational residue across complex workflows.

Public positioning:

- framework for coordination, evidence, memory and handoffs;
- prototype / research system / public demo;
- local-first engineering method with explicit gates before external action.

Non-claims:

- not presented as demonstrated autonomous general intelligence;
- not presented as validated physics;
- not a guarantee of autonomous correctness.

The public release exposes concepts and demos only. Private canon, source vaults, credentials, local runtime logs and uncurated archives are excluded.
