# Open Core vs Protected MEDIOEVO Assets

This matrix is a public-safe boundary document. It is not a transfer of private material into open source.

## MIT / Open-Core Candidates

These can be published under MIT after target-specific review, tests and scans:

| asset | public use | boundary |
|---|---|---|
| Schemas | shared contracts for TaskSpec, Source Cards, WitnessLog and artifacts | synthetic examples only |
| Validators | local checks for claims, paths, gates and manifests | no private workspaces or secrets |
| ActionGate demo | APPROVE / REVIEW / BLOCK examples | no guarantee of absolute safety |
| WitnessLog demo | append-only event examples | no private logs or sessions |
| Source Card contract | compact provenance and claim cards | no raw private documents |
| Artifact contract | renderable HTML/JSX/JSON/media metadata | no private sources or binaries |
| Falsifier templates | claim downgrade and negative-test patterns | no proof of new physics |
| Synthetic fixtures | demos for tests and docs | no real datasets |

## Proprietary / Commercial / All Rights Reserved

These remain protected unless a separate release explicitly changes their status:

| asset | posture | reason |
|---|---|---|
| MEDIOEVO books and complete canon | all rights reserved | core creative IP |
| LORE vault and private world material | all rights reserved | private canon and continuity |
| RPG/TCG systems and assets | proprietary/private | game IP and unreleased worlds |
| Wabi-Sabi internals | proprietary/private | local operator runtime |
| Full OSIT packets | proprietary/research | unreviewed theory, formulas and calibration |
| Commercial apps and UI shells | proprietary/commercial | sellable products and support surface |
| Premium agents and templates | proprietary/commercial | monetization lane |
| Installers and product bundles | proprietary/commercial | packaged deliverables |
| Video and audio sources | protected source assets | platform and rights review required |
| Credentials, accounts and local datasets | never public | security and privacy boundary |

## Public Claim Boundary

Use language like:

- formal lab;
- synthetic demo;
- local-first tooling;
- evidence before action;
- designed to reduce informational residue;
- public-safe open foundations.

Do not use language like:

- general-intelligence achievement wording;
- consciousness-resolution wording;
- new-physics proof wording;
- prediction guarantees;
- absolute safety guarantees;
- medical, legal or financial guarantee.
