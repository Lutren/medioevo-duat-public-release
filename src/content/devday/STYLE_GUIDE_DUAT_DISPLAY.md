# DUAT Adaptive Intelligence Display — Visual Style Guide

## Style vector
Premium product-keynote interface; dark navy/black base; luminous cyan, teal, and blue edges; glass HUD panels; geospatial context; multi-agent orchestration; persistent memory; workflow graph; clean operational labels.

## Core palette
- Background: `#030911` / `#061626`
- Panel: `#071525` / `#0A2135`
- Cyan primary: `#24E8FF`
- Teal accent: `#00F5D4`
- Blue accent: `#3E7BFF`
- Purple secondary: `#8A5CFF`
- Amber caution/ops: `#FFD166`
- Green operational: `#45FF98`
- Text: `#F4FBFF` / `#8CB7C9`

## UI rules
1. Use large dark surfaces with thin luminous borders.
2. Keep glow subtle; do not flood the screen with neon.
3. Use modular panels: Agent Orchestration, Geospatial Context, Memory Status, Workflow Graph, Knowledge Integration.
4. Prefer small uppercase labels and clean numeric telemetry.
5. Make every visual asset communicate structure, not decoration.
6. For contest visuals, describe DUAT as an orchestration display/prototype unless externally validated.
