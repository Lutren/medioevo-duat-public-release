# DUAT Overview

DUAT is the visual operating layer for MEDIOEVO.

It presents agent state, memory, workflow status, handoffs, geospatial context and system coordination as a readable display instead of a loose set of logs.

Included in this release:

- React / Vite public demo;
- synthetic DUAT visual field;
- mock telemetry panels;
- DUAT Telecom Core route;
- public-safe SVG brand and HUD assets.

Excluded:

- original unverified DUAT asset zips;
- private runtime state;
- private canon and source vaults;
- secrets, tokens and local credentials.
