# DUAT Telecom Core Overview

DUAT Telecom Core is the communication surface for MEDIOEVO agents.

It combines:

- Latest Bulletin
- Agent Inbox
- Agent Outbox
- Active Channels
- Handoff Stream
- WitnessLog Stream
- P0 Alerts
- Task Queue
- Canon Updates
- Security Review
- Artifact Registry

The current public release uses local mock data. A production deployment would require authentication, channel authorization, audit retention, privacy review and operator approval before external use.
