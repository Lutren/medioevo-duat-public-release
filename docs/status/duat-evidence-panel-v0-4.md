# DUAT Evidence Panel v0.4 - Public-Safe Summary

DUAT v0.4 is a local evidence panel for tracking the state of a simulation and runtime workflow.

## What It Shows

- Active canon status.
- Fragmentos QA status.
- Simulation evidence.
- Runtime reconstruction status.
- Falsifier status.
- Replay status.
- Gate distribution.
- Blockers and next actions.

## Method

The panel is evidence-first. It treats a result as useful only when it can be traced to local artifacts, tests, gates or reconstruction output.

## Boundary

This public summary does not expose the internal panel JSON, private runtime internals, full reports, local paths, source text or private materials.

## Status

The v0.4 panel exists locally and is used as an internal evidence surface. The public release only describes the method and status.
