# Security Policy

This public release is curated from local MEDIOEVO / DUAT sources.

Do not include:

- `.env` or `.env.*`
- API keys, tokens, credentials, private keys or service accounts
- `99_SOURCE_VAULT`, raw archives, unreviewed zips or internal logs
- files marked `SECURITY_REVIEW`, `PRIVATE`, `DO_NOT_PUBLISH` or `INTERNAL_ONLY`
- private game, TCG, paid-source or vault material

Publication remains blocked unless the staged release passes a focused secret scan, file-name scan, build and human target confirmation for GitHub and deploy.

Report security issues privately to the project owner before public disclosure.
