Observacionismo and OSIT

A public explanation of the theory layer behind MEDIOEVO, framed as proposed theory and engineering method rather than validated universal science.

Observacionismo

Observacionismo is an epistemological and engineering method for AI agent workflows. The observer does not process from zero; it processes from a state. That state determines whether information is absorbed, distorted or amplified.

Observe → Classify → Verify → Act → WitnessLog → Handoff

OSIT — Observational State-Induced Tensor

OSIT is a proposed formal framework for state-aware information processing. It treats receiver state as an operational constraint on usable information.

H_eff(X | R) = H(X) · Φ_eff(R)
variablemeaning
RInformational Residue: open loops, contradictions, pending decisions and unvalidated claims.
Φ_effEffective conversion from input into understanding, action and artifact.
J_cJamming threshold where more input produces less clarity.

DO → IOI

DO, Deconstrucción Observacionista, decomposes a source into claims, risks, missing data, dependencies and traceable signals. IOI, Ingeniería Observacionista Inversa, reconstructs the required artifact, architecture, schema or test from a verified target outcome.

Claim boundary

This work should not be described as achieved AGI, solved consciousness, validated new physics or guaranteed agent safety. The accurate public framing is proposed theory, engineering method, public tooling and research prototypes.
