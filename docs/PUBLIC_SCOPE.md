# Public Scope

## Included

- MEDIOEVO public overview.
- DUAT as an orchestration display and prototype.
- DUAT Telecom Core as a mock MessageBus dashboard.
- HandoffHub as a continuity concept.
- WitnessLog and ActionGate as release-governance patterns.
- Wabi-Sabi as an orchestration / cognitive layer.
- CEREBRO as a canon and structured-memory layer.
- Claudio as a local-first operator/runtime concept.

## Excluded

- private canon and vaults;
- credentials, tokens, keys and local account state;
- private game / TCG / RPG material;
- raw Replit or Lovable archives;
- raw DUAT asset ZIPs;
- internal prompt packs;
- files marked `SECURITY_REVIEW`, `PRIVATE`, `INTERNAL_ONLY` or `DO_NOT_PUBLISH`;
- unsupported AGI, physics or prediction claims.

## Claim Boundary

DUAT is described as an orchestration display, prototype and public demo. It is not described as externally verified AGI.
