# DUAT Telecom Core

DUAT Telecom Core is a public demo of agent communication state.

The `/telecom` route includes:

- Latest Bulletin
- Agent Inbox
- Agent Outbox
- Active Channels
- Handoff Stream
- WitnessLog Stream
- P0 Alerts
- Task Queue
- Canon Updates
- Security Review
- Artifacts

The current release uses mock local data. A production backend would need authentication, per-channel access control, audit logs and retention rules before public operation.
