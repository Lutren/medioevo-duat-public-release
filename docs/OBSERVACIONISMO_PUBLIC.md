# Observacionismo Public Boundary

The public layer frames Observacionismo as an engineering lens for observability, residue reduction, evidence and continuity.

Allowed public framing:

- operational residue;
- agent coordination;
- evidence-backed release engineering;
- public-safe diagrams and UI demos;
- prototype and research language.

Do not publish:

- private theory notes;
- full canon vaults;
- proprietary formulas or unreviewed claims;
- private runtime logs;
- material marked private, internal or security review.

Strong claims must be downgraded to prototype / research / demo unless verified by evidence appropriate to the claim.
