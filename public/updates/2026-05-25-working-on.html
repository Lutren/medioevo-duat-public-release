Public-safe update · May 25, 2026

What I am building now

MEDIOEVO is moving toward a local-first visual workbench for AI agents: artifacts first, evidence before action, explicit boundaries for public work and protected private canon.

Open foundationsFormal labProtected canon excluded

Wabi visual artifacts

Wabi is being shaped as a local workbench that opens renderable artifacts by default: HTML, JSX, PDF, image, audio, video and JSON previews before raw source text.

OSIT Formal Lab

OSIT public work stays in a reproducible formal-lab lane: residue, gates, source cards, falsifiers and synthetic examples. It is not presented as new-physics validation.

Agent City

Each app and NPC is treated as a specialized agent with role, memory, limits, tools and background. The public layer shows the design pattern, not private runtime state.

Token economy

Source Cards, manifests, hashes and artifact-first previews are used to reduce repeated context and keep long sessions from asking unnecessary clarifications.

What is public

  • MIT-friendly schemas, validators, Source Card patterns, ActionGate demos, WitnessLog demos and TaskSpec examples.
  • Synthetic demos and low-claim public summaries for DUAT, Wabi, OSIT and local-first agent workflows.
  • Public-safe writeups about evidence before action, state-aware processing and release discipline.

What stays protected

  • Full MEDIOEVO books, LORE, private canon, private prompt systems, Wabi internals, complete OSIT packets and proprietary calibration.
  • Commercial apps, premium UI shells, agent products, installers, templates, support workflows and private lab setup.
  • RPG/TCG systems, world assets, private source, complete videos/audio sources, credentials, accounts and unpublished datasets.
